# RIVAL

目標に向かって走る「ライバル」を作り、今日のタスクと架空の成果レポートで毎日の一歩を応援するローカルWebアプリです。

## 起動方法
`index.html` をブラウザで開いてください。目標、進捗、完了タスク、チャット履歴はブラウザの `localStorage` に保存されます。

## 機能
- 目標・期限・1日の取り組み時間の設定
- ライバルのプロフィールとアバター
- 日々のタスク提案、達成状況、連続日数
- ライバルからの架空の日次レポート
- 目標に応じたローカル定型チャット

外部AI/APIを使用しないため、会話やレポートはアプリ内のルールに沿って生成されます。
